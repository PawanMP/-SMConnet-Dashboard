Privacy Policy

How Social Poster handles your account credentials and media data

1. Data Storage & Security

All API access tokens, channel credentials, and passwords are stored securely in local configuration files or server environment variables. Your credentials are used exclusively to authorize posting requests to connected social platforms.

2. Session Authentication

Login authentication token sessions are kept in browser sessionStorage. Closing the browser window automatically logs you out to preserve account security.
