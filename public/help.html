Setup & Publishing Help Guide

Step-by-step instructions to get API keys, schedule content, and publish

🚀 Quick Start Checklist

  1. Navigate to individual platform settings (Facebook, Instagram, YouTube, TikTok, Pinterest) in the sidebar.
  2. Enter your API Access Tokens, Page IDs, or Channel IDs for each channel you wish to use.
  3. (Optional) Configure your OpenAI API Key under AI Settings for auto-generated captions and hashtags.
  4. Go to the Dashboard, upload photo or video media, pick target platforms, draft captions, and hit Publish Now or Schedule Post.

📅 Post Scheduling System

When scheduling posts, you can set individual date-time pickers per platform or use the Bulk Schedule Picker to set a unified publishing time across all accounts. View and manage queued posts under the Scheduled Posts page.
