Help guide

How to connect accounts, create posts, schedule them and read the results.

Getting started

  1. Open Connected accounts and choose Connect for each platform you use. You sign in on the platform's own page and approve access.
  2. Go to Create post, add a photo or video, pick platforms and write your text.
  3. Choose Publish now, Schedule or Save as draft.
  4. Follow results on the Dashboard, Post history and Analytics pages.

Connecting accounts

Each user connects their own accounts. Tokens are encrypted on the server; the browser never sees them.

Facebook

You need to be an admin of a Facebook Page. After connecting, choose which Page to publish to on the Accounts page. Text-only posts, photos and videos are supported.

Instagram

The account must be a Business or Creator (professional) account. Instagram needs a photo or video for every post. Images are converted to JPEG automatically when Cloudinary is configured.

YouTube

Sign in with the Google account that owns the channel. Only videos can be uploaded. The title comes from the YouTube title field, or the first line of the caption.

TikTok

Only videos are supported. Until TikTok approves the app for public posting, videos may be posted as private (only visible to you).

Pinterest

After connecting, choose the board Pins should go to. Pins need an image or a video.

Connection status

  • Connected: ready to publish. YouTube, TikTok, Pinterest and Instagram tokens renew automatically.
  • Token expired: the platform no longer accepts the token (it expired or you removed access). Choose Reconnect.
  • Not connected: no credentials are stored.

If sign-in for a platform is not set up on the server yet, you can connect with an access token from the platform's developer tools instead (under "Connect with an access token instead").

Creating posts

  • The All platforms tab holds shared text. Each platform tab can override it, for example a shorter TikTok caption.
  • The Ready to go? panel lists anything that would stop a platform from accepting the post, such as a missing video for YouTube.
  • The AI assistant writes captions, titles, descriptions and hashtags per platform in the tone you choose. Always review the text before publishing.

Scheduling

Pick a date and time, or use a different time per platform. The scheduler checks every 30 seconds and publishes posts when they are due. Schedules are stored in the database, so they survive server restarts.

  • Edit or reschedule a post any time before it starts publishing.
  • Publish now on a scheduled post publishes it immediately.
  • Temporary platform errors are retried automatically, up to 2 times.
  • Posts missed by more than 24 hours (for example because the server was offline) are not posted late; they are marked failed so you can decide.

When a platform fails

Each platform succeeds or fails independently. A post can be Partly published: live on some platforms, failed on others. Open the post to see each error, fix the cause, then choose Retry. Retrying only republishes the failed platforms, never the ones that already succeeded.

Analytics

Publishing figures come from this system. Views, likes and comments come from each platform's API where it allows it; choose Refresh engagement data to update them. Some numbers need extra permissions from the platform and may show as unavailable.

Security tips

  • Use a strong, unique password. Changing it signs out your other devices.
  • Use Sign out of all devices on the Profile page if you used a shared computer.
  • Disconnecting an account deletes its stored tokens immediately.
