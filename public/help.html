Setup & Publishing Help Guide

Step-by-step instructions to get API keys, schedule content, and publish

🚀 Quick Start Checklist

  1. Navigate to individual platform settings (Facebook, Instagram, YouTube, TikTok, Pinterest) in the sidebar.
  2. Enter your API Access Tokens, Page IDs, or Channel IDs for each channel you wish to use.
  3. (Optional) Configure your OpenAI API Key under AI Settings for auto-generated captions and hashtags.
  4. Go to the Dashboard, upload photo or video media, pick target platforms, draft captions, and hit Publish Now or Schedule Post.

📅 Post Scheduling System

When scheduling posts, you can set individual date-time pickers per platform or use the Bulk Schedule Picker to set a unified publishing time across all accounts. View and manage queued posts under the Scheduled Posts page.

📖 Integration Guide: Connecting Your Accounts & AI

1. Facebook (Page ID & Access Token)

Step A (Get your Page ID):
Go to Facebook, switch into your specific Facebook Page profile, and click on your Page's name to view your main timeline. Look at the browser URL at the top; the long string of numbers (e.g., 1019610687906644) is your Facebook Page ID. (Alternatively, find it under your Page's About > Overview or Page transparency section).

Step B (Get your Page Access Token):

  1. Go to the official Meta Graph API Explorer.
  2. In the top-right corner, select your created developer app under the Meta App dropdown.
  3. Under the User or Token dropdown, select Get Page Access Token and choose your specific Facebook Page.
  4. Under the Permissions dropdown, add and select: pages_manage_posts and pages_read_engagement.
  5. Click Generate Access Token, copy the generated long token string (starting with EAA...), and paste it into your dashboard.

2. Instagram (Business Account ID & Access Token)

Step A (Prerequisite): Ensure your Instagram account is switched to a Business or Creator Account and is linked directly to your Facebook Page.

Step B (Get your Instagram Account ID):

  1. Go back to the Meta Graph API Explorer.
  2. Ensure you have added the instagram_basic and instagram_content_publish permissions.
  3. In the query bar at the top, type GET /v21.0/me?fields=instagram_business_account and click Submit.
  4. Copy the ID returned under instagram_business_account.

Step C (Link to System): Paste your Instagram Account ID and the exact same Facebook Page Access Token into your dashboard's Instagram Settings.

3. YouTube (Google Data API v3)

Step A (Enable API):
Go to the Google Cloud Console and create a new project. Navigate to APIs & Services > Library, search for YouTube Data API v3, and click Enable.

Step B (Create Credentials):
Go to Credentials > Create Credentials > OAuth client ID (configure the OAuth Consent Screen if prompted). Select Web application as the application type and add your deployment URL under authorized redirect URIs.

Step C (Generate Token):
Use the Google OAuth 2.0 Playground. Check the box to use your own OAuth Client ID and paste your created Client ID and Client Secret. Select the YouTube Data API v3 scope (https://www.googleapis.com/auth/youtube.upload), click Authorize APIs, sign in, and click Exchange authorization code for tokens to copy your Access Token.

Step D (Link to System): Paste your YouTube Channel ID (found in your YouTube advanced settings) and the Access Token into your dashboard's YouTube Settings.

4. TikTok (Client Key, Secret, & OAuth)

Step A (Create an App):
Go to the TikTok Developer Portal and create an account. Click Manage Apps > Create App, select Web as the platform, and apply for the Video Publishing permission (video.upload).

Step B (Get Credentials): Once approved, copy your assigned Client Key and Client Secret from your app panel.

Step C (Generate Token): Authenticate your TikTok account through your app's OAuth2 authorization flow to generate a valid User Access Token.

Step D (Link to System): Paste your Client Key and Access Token into your dashboard's TikTok Settings page.

5. Pinterest (App ID, Board ID, & v5 API Token)

Step A (Create an App):
Go to the Pinterest Developers Portal and create an app to get your App ID.

Step B (Get your Board ID):
Open the Pinterest Board where you want to post. You can find your Board ID number by typing https://api.pinterest.com/v3/boards/{your-username}/{board-name}/ into your browser.

Step C (Generate Token): Use the OAuth process in the Pinterest Developer portal to authorize boards:read, boards:write, pins:read, and pins:write permissions to output your Access Token.

Step D (Link to System): Paste your App ID, Board ID, and Access Token into your dashboard's Pinterest Settings.

6. OpenAI / Gemini AI (API Key & Model Configuration)

Step A (Create an Account): Go to the official OpenAI Platform website and sign in or create a new account.

Step B (Navigate to API Keys): Click on your profile icon or go directly to the OpenAI API Keys page.

Step C (Generate Key): Click + Create new secret key, name it (e.g., "Social Dashboard"), and click Create secret key.

Step D (Copy and Save): Copy the secret key immediately (it starts with sk-...), as it will not be shown again.

Step E (Link to System): Paste your key into the OpenAI API Key input field on your dashboard, select your preferred model (such as gpt-4o-mini), and click Save Configuration.
