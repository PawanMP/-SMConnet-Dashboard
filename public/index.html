Setup Help Guide

Step-by-step instructions to connect your accounts

📘

Connecting Facebook

1. Get your Page ID: Go to your Facebook Page > About > Page Transparency.

2. Generate Access Token: Use the Meta Graph API Explorer.

3. Permissions: Ensure you add pages_manage_posts, pages_read_engagement, and publish_video.

4. Save: Paste the Page ID and Token in Facebook Settings.

📸

Connecting Instagram

1. Link Accounts: Ensure your IG Business account is linked to your Facebook Page.

2. Get IG ID: In Graph Explorer, call GET /me?fields=instagram_business_account.

3. Permissions: Add instagram_basic and instagram_content_publish.

4. Save: Paste the IG ID and same Page Token in Instagram Settings.

📽️

Connecting YouTube

1. Get Channel ID: Go to YouTube Studio > Settings > Customization > Basic Info.

2. Generate Access Token: Use the Google OAuth2 Playground.

3. Scopes: Select YouTube Data API v3 and the youtube.upload scope.

4. Save: Paste your Channel ID and Access Token in YouTube Settings.

🎵

Connecting TikTok

1. Create Developer App: Go to TikTok for Developers.

2. Add Content Posting API: Enable the Content Posting API product.

3. OAuth Flow: Complete the OAuth authorization flow to get your access token.

4. Save: Paste your credentials in TikTok Settings.

📌

Connecting Pinterest

1. Create Developer App: Go to Pinterest for Developers.

2. Request Pins API: Request access to the Pins API from your dashboard.

3. Generate Token: Generate an Access Token from the app dashboard.

4. Save: Paste your credentials in Pinterest Settings.

💡 Pro Tip: Tokens from the Explorer are short-lived (2 hours). For long-term use, use the "Access Token Tool" in the Meta Developer Portal to generate 60-day tokens.

🛡️ Privacy Policy

Data privacy practices and platform API compliance guidelines for Social Poster v4.0

1. Overview & Application Scope

Social Poster is a multi-platform social media management application designed to help users create, schedule, and publish content across social networks including Facebook, Instagram, YouTube, TikTok, and Pinterest.

We are committed to maintaining the trust and confidence of our users by upholding strict data protection standards and protecting the security of your connected accounts.

2. Information Collection, Storage & Use
  • Local Credential Storage: Your authentication credentials (Page IDs, Access Tokens, Client Keys, and API secret keys) are stored locally on your application server within configuration files (config.json). They are used strictly to sign API requests to third-party platforms on your behalf.
  • Media Upload Processing: Media files (images and videos) uploaded for publishing or scheduling are processed through the local uploads/ directory. Media is retained temporarily to complete scheduled or immediate platform uploads, after which temporary files are purged.
  • AI Captions & Vision Assistance: If enabled, prompt texts and image previews may be submitted to OpenAI APIs strictly for content generation. No training data or user credentials are shared.
  • No Data Selling or Sharing: Social Poster does not sell, rent, monetize, or transfer your personal data, tokens, media uploads, or connected account metrics to any third parties or advertising networks.
3. Third-Party API Services & Compliance

Social Poster integrates with third-party social media platform APIs. By using these features, you agree to comply with the respective platform policies:

📘 Meta (Facebook & Instagram)

Uses Meta Graph API to read page details and publish user-selected media. Adheres to Meta Developer Policies and Platform Terms.

📽️ YouTube (Google API Services)

Uses YouTube Data API v3. Users are bound by the YouTube Terms of Service and Google Privacy Policy.

🎵 TikTok

Uses TikTok Content Posting API. Video content and metadata are uploaded strictly according to TikTok Developer Guidelines.

📌 Pinterest

Uses Pinterest Pins API to create Pins on user-specified boards in compliance with Pinterest API Terms.

4. User Controls, Revocation & Data Deletion

You retain full control over your data and connected account permissions:

  • Clear Saved Credentials: You can remove or overwrite saved access tokens anytime within each platform's settings screen in this dashboard.
  • Revoke API Access: You can revoke Social Poster's access to your social media accounts at any time directly through each platform's app security settings:
    • Google / YouTube: Google Security Permissions
    • Meta / Facebook / Instagram: Meta Business Integrations
    • TikTok: TikTok Security Settings
    • Pinterest: Pinterest Connected Apps
  • Data Purge: Deleting the local configuration file or uninstalling the server removes all local settings, scheduled tasks, and session records permanently.
5. Security & Updates

Admin dashboard access is protected by token-based authentication. We periodically update this privacy policy to reflect new features and API requirement changes.
