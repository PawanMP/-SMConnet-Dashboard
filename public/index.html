How to get your credentials
  1. Go to developers.facebook.com → Create App → Business
  2. Open Graph API Explorer and select your app
  3. Click Generate Access Token, grant pages_manage_posts & pages_read_engagement
  4. Switch the dropdown from User Token to your Page name — this gives you a Page Access Token
  5. Copy the token and your Page ID (found on your Page → About) into the fields above

How to get Instagram credentials
  1. Your Instagram account must be a Business or Creator account linked to a Facebook Page
  2. In Graph API Explorer, add permissions: instagram_basic, instagram_content_publish, pages_read_engagement
  3. Generate a Page Access Token (switch dropdown to your Page)
  4. Call GET /{page-id}?fields=instagram_business_account to get your IG Account ID
  5. Paste both values into the fields above

YouTube Credentials
Found in YouTube Studio → Settings → Advanced Settings
Generate from Google OAuth2 Playground with youtube.upload scope
How to get YouTube credentials
  1. Go to Google Cloud Console and enable YouTube Data API v3
  2. Create OAuth 2.0 credentials (Client ID + Secret)
  3. Go to OAuth2 Playground and select YouTube Data API v3 → youtube.upload
  4. Authorize APIs and exchange the authorization code for tokens
  5. Copy the Access Token and your Channel ID into the fields above

Setup Help Guide

Step-by-step instructions to connect your accounts

📘

Connecting Facebook

1. Get your Page ID: Go to your Facebook Page > About > Page Transparency.

2. Generate Access Token: Use the Meta Graph API Explorer.

3. Permissions: Ensure you add pages_manage_posts, pages_read_engagement, and publish_video.

4. Save: Paste the Page ID and Token in Facebook Settings.

📸

Connecting Instagram

1. Link Accounts: Ensure your IG Business account is linked to your Facebook Page.

2. Get IG ID: In Graph Explorer, call GET /me?fields=instagram_business_account.

3. Permissions: Add instagram_basic and instagram_content_publish.

4. Save: Paste the IG ID and same Page Token in Instagram Settings.

📽️

Connecting YouTube

1. Get Channel ID: Go to YouTube Studio > Settings > Customization > Basic Info.

2. Generate Access Token: Use the Google OAuth2 Playground.

3. Scopes: Select YouTube Data API v3 and the youtube.upload scope.

4. Save: Paste your Channel ID and Access Token in YouTube Settings.

🎵

Connecting TikTok

1. Create Developer App: Go to TikTok for Developers.

2. Add Content Posting API: Enable the Content Posting API product.

3. OAuth Flow: Complete the OAuth authorization flow to get your access token.

4. Save: Paste your credentials in TikTok Settings.

📌

Connecting Pinterest

1. Create Developer App: Go to Pinterest for Developers.

2. Request Pins API: Request access to the Pins API from your dashboard.

3. Generate Token: Generate an Access Token from the app dashboard.

4. Save: Paste your credentials in Pinterest Settings.

💡 Pro Tip: Tokens from the Explorer are short-lived (2 hours). For long-term use, use the "Access Token Tool" in the Meta Developer Portal to generate 60-day tokens.
