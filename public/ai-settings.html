Getting an API key

OpenAI

  1. Sign in at platform.openai.com/api-keys.
  2. Choose Create new secret key and copy it (it starts with sk-).

Google Gemini

  1. Open Google AI Studio.
  2. Choose Create API key and copy it (it starts with AIza).
