Getting an API key

OpenAI

  1. Sign in at platform.openai.com/api-keys.
  2. Choose Create new secret key and copy it (it starts with sk-).

Google Gemini

  1. Open Google AI Studio.
  2. Choose Create API key and copy it (it starts with AIza).

OpenRouter

  1. Sign in at openrouter.ai/keys.
  2. Choose Create Key and copy it (it starts with sk-or-).

OpenRouter gives access to many models (OpenAI, Anthropic, Google, Meta and more) through one key, including some free-tier models. Model names must include the vendor prefix, e.g. openai/gpt-4o-mini.
